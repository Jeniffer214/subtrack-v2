# 用户访谈提纲：Printlens 澄数

> 目标：用 10 场访谈验证（或推翻）调研中的关键假设，再决定是否投入数据成本。
> 时长：每场 45 分钟 ｜ 形式：线上视频，征得同意后录音 ｜ 访谈人：1 主访 + 1 记录

## 1. 要验证的假设

| 编号 | 假设（来自 RESEARCH.md） | 什么答案算"成立" | 什么答案算"不成立" |
|---|---|---|---|
| H1 | 交易员不信任现有日历的影响等级（P1） | 能说出一次因评级不准/被改而误判的具体经历 | 从未质疑过评级，直接照用 |
| H2 | 交易员关心"预期差"但缺少现成的量化工具（P2） | 目前靠手算、Excel 或凭感觉判断意外程度 | 已有满意的工具在做这件事 |
| H3 | 时区/夏令时导致过错过事件（P3） | 过去一年有过具体一次 | 从未发生 |
| H4 | 信息过载，只想看影响自己持仓的事件（P5） | 自己做过筛选/自建列表来应对 | 全量浏览没有负担 |
| H5 | 中文交易员找不到带量化分析的中文日历（P7，**最关键**） | 在中英文工具间来回切换，或说不出一个满意的中文工具 | 金十/见闻等已完全满足 |
| H6 | 愿意为"透明可验证"的分析付费 | 当前已在为同类工具付费，或当场愿意预付/留联系方式内测 | 只用免费工具，也不打算付费 |

**决策规则（访谈前定好，避免事后解读）**：10 人中 H5 成立 ≥ 6 人 且 H6 成立 ≥ 3 人 → 进入接真实数据阶段；H5 成立 ≤ 3 人 → 重新评估"中文优先"定位（改为英文或双语）。

## 2. 招募

**目标画像（10 人）**

| 类型 | 人数 | 说明 |
|---|---|---|
| 外汇/黄金日内或波段交易者 | 4 | 核心用户，重度依赖经济日历 |
| 美股/指数期货交易者 | 3 | 关注 CPI、非农、FOMC |
| 关注 A 股/港股、兼看宏观数据的投资者 | 2 | 验证中国数据（CPI、PMI、LPR）需求 |
| 券商/自营从业者 | 1 | 验证 B2B 白标方向 |

**筛选问题**（全部满足才邀请）
1. 过去 3 个月里，是否至少每周看一次经济日历？
2. 是否有过因为一项数据公布而开仓、平仓或调仓？
3. 是否在实际交易（非模拟盘）？

**排除**：亲友、同事、投资我们的人（会客气）；只看新闻不交易的人。
**渠道**：交易社群（微信群、知乎、雪球）、券商客户群、Twitter/X 中文交易圈。
**激励**：建议 100–200 元购物卡或 3 个月 Pro 会员（上线后兑现）。

## 3. 访谈流程（45 分钟）

### 开场（3 分钟）
- 说明目的："我们在研究交易员怎么使用经济数据，**不是推销**，你说我们的想法不好对我们最有帮助。"
- 征得录音同意，说明录音仅内部使用、可随时要求删除。
- **不评价对方的交易策略，不给任何买卖建议。**

### A. 背景（5 分钟）
1. 你主要交易什么品种？大概多长的持仓周期？
2. 交易多久了？主要用什么平台下单？

### B. 现有工作流（12 分钟）—— 只问过去发生的事
> 原则：问"上一次你是怎么做的"，不问"你会不会"。

3. **上一次**你因为一项经济数据做交易决定，是哪个数据？从知道它要发布到下单，你具体做了什么？（追问：打开了哪些网站/App，按什么顺序）
4. 你现在用哪些工具看日历和数据？每个工具用来干什么？（记下所有工具名）
5. 这些工具里，有没有**付费**的？多少钱？为什么愿意付？
6. 数据公布后，你怎么判断这个数字"算好还是算坏"？（追问：会不会看它比预期高多少？怎么算的？）→ H2
7. 你怎么决定哪些事件值得关注、哪些可以忽略？→ H4

### C. 痛点挖掘（10 分钟）
8. 最近一次**因为日历或数据相关的原因**亏钱或错过机会，是什么情况？（不提示方向，先让对方自己说）
9. （若未提到）有没有遇到过日历上的影响等级和实际行情差很多的时候？你当时怎么想的？→ H1
10. （若未提到）有没有因为时区、夏令时记错过发布时间？→ H3
11. （中文用户）你看数据主要用中文还是英文工具？为什么？有没有觉得哪个中文工具缺了什么？→ H5
12. 如果明天这些工具全都不能用了，你最舍不得哪一个？为什么？

### D. 原型测试（10 分钟）
> 共享屏幕，打开 MVP（先说明是演示数据）。**不讲解，让对方自己操作并出声思考。**

13. 任务一："找出本周对你交易的品种影响最大的事件。"（观察：会不会用"关注资产"筛选）
14. 任务二："打开一个事件，告诉我这个影响分是怎么来的，你信不信它。"（观察：能否看懂公式和样本量；透明度是否真的提升信任）→ H1
15. 任务三："点'生成解读'，读一下，哪句有用，哪句是废话？"
16. 看完之后，这个东西会替代你现在工具里的哪一个？还是只是多一个工具？

### E. 付费意愿（3 分钟）→ H6
17. 你现在每月在交易工具/数据上一共花多少钱？
18. 我们打算开一个小范围内测，需要留一个联系方式，你愿意吗？（**行为承诺比口头"会买"可信**）
19. （仅当对方主动表现兴趣时）如果这个工具每月 X 元，你觉得贵、合理还是便宜？（X 分别测 29 / 69 / 129 元，每人只测一个价位）

### 收尾（2 分钟）
20. 还有什么我应该问却没问的？
21. 你身边还有谁适合聊这个话题？能帮忙介绍吗？

## 4. 访谈人注意事项

| 做 | 不做 |
|---|---|
| 问具体的过去行为（"上一次…"） | 问假设性问题（"你会不会用…"） |
| 对方说"不错"时追问"具体哪里" | 把客套话当成需求验证 |
| 沉默 3 秒，让对方补充 | 急着解释产品或替产品辩护 |
| 原话记录，标注是主动提到还是被提示后提到 | 当场总结对方的意思 |
| 对方问建议时回答"我们在研究，不提供交易建议" | 讨论具体的买卖方向 |

## 5. 记录与汇总模板

每场访谈结束 24 小时内填写一行：

| 编号 | 画像 | 现用工具（付费的标 $） | 月支出 | H1 | H2 | H3 | H4 | H5 | H6 | 最痛的一件事（原话） | 原型最有用/最没用 | 留了内测联系方式？ |
|---|---|---|---|---|---|---|---|---|---|---|---|---|
| 01 | | | | ✅/❌/— | | | | | | | | 是/否 |

- ✅ = 主动提到且有具体经历；🟡 = 被提示后认同；❌ = 明确否定；— = 未涉及
- **只有 ✅ 计入决策规则中的"成立"人数**，🟡 单独统计作参考

10 场结束后，按第 1 节的决策规则得出结论，并更新 `RESEARCH.md` 中各痛点的置信度。
